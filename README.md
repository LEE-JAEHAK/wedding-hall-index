# 서울 웨딩홀 비교 인덱스

2026년 10월 13일 기준 웨딩북과 아이웨딩의 공개 정보를 서울 강남구·영등포구(여의도동 포함) 범위에서 수집했습니다. 현재 목록은 웨딩북 71곳·홀 110건, 아이웨딩 76곳·홀 121건입니다. 동일 장소 69곳을 묶은 통합 목록은 78곳입니다. 기본 화면은 홀별 정보 229행을 바로 표시합니다. 아이웨딩에만 7곳, 웨딩북에만 2곳이 있습니다.

## 열기

배포 사이트: https://lee-jaehak.github.io/wedding-hall-index/

GitHub Pages는 `main` 브랜치의 루트 폴더를 배포합니다. 변경 사항을 `main`에 push하면 사이트가 자동으로 갱신됩니다.

[index.html](index.html)을 브라우저에서 열면 됩니다. `index.html`, `style.css`, `compare.css`, `app.js`, `weddingbook_data.js`, `iwedding_data.js`를 같은 폴더에 두세요. 검색, 지역·출처·식사 형태·인원·가격·주차 필터가 있습니다. 표 머리글을 누르면 오름차순·내림차순을 전환합니다. 현재 결과를 CSV로 저장할 수 있습니다.

웨딩북 `추천인원`과 아이웨딩의 `최소 인원`, `착석 인원`, `최대 수용인원`은 별개입니다. 아이웨딩의 장소 전체 `보증 인원`과 홀별 최소 인원도 별도로 보존했습니다. 캐시백 적용을 위한 웨딩북의 보증 인원 조건은 계약상 최소 보증인원으로 해석하지 않았습니다.

기본 목록은 홀별 행이며 검색·필터·정렬도 각 행에 적용됩니다. 두 사이트의 공통 홀 항목(홀 이름·대관료·식대·예식 간격·꽃장식·식사 형태·주소·주차 대수)이 모두 같으면 한 행으로 합치고, 하나라도 다르면 출처별 두 행으로 분리합니다. 한 사이트에만 있는 인원·비용 항목은 해당 출처의 행에 표시합니다. 이름이나 주소만으로 홀 대응이 불명확한 경우에도 별도 홀 정보로 남깁니다. 자세한 정보는 각 행의 원본 링크에서 확인할 수 있습니다. CSV는 기존 예식장 단위 형식을 유지하며 비교 전 원값을 각각 별도 열로 담습니다.

검색어·필터·정렬은 같은 브라우저에 자동 저장되어 브라우저를 종료했다 다시 열어도 복원됩니다. `필터 초기화`를 누르면 저장된 조건도 초기화됩니다.

## 원본과 주의할 점

- [웨딩북 원본 JSON](weddingbook_venues_2026-10-13.json), [아이웨딩 원본 JSON](iwedding_venues_2026-10-13.json)에 수집 텍스트와 상세 페이지 URL이 있습니다.
- 가격, 수용인원, 주차는 각 사이트의 게시값입니다. 대관료와 꽃장식·연출료의 포함 범위가 다를 수 있으며, 실제 견적과 계약 조건은 상담에서 확인해야 합니다.
- 아이웨딩의 최대 수용인원 중 일부는 착석 인원보다 훨씬 크게 표시됩니다. 화면은 값을 임의 수정하지 않고 두 수치를 따로 보여줍니다.
- 웨딩북 홀의 연도별 표기와 아이웨딩 홀 이름이 다를 수 있습니다. 같은 장소라도 홀 대응이 확실하지 않으면 합치지 않았습니다.
- 공개 페이지의 사진 파일과 후기 본문은 수집하지 않았습니다. 각 행의 원본 링크에서 확인할 수 있습니다.
